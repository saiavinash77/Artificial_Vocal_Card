1. System Overview
Sathvani AVC is a distributed edge-cloud architecture that restores natural, personalized speech for people who have
lost their voice (laryngectomy, vocal-cord paralysis, ALS). Physiological signals captured by a wearable mask are
streamed to the cloud, reconstructed into phonemes by a CNN-BiLSTM-Attention model, converted into words via
dictionary + language-model re-ranking, and synthesized into personalized speech using FastSpeech2 + HiFi-GAN.
2. End-to-End Architecture Flow
The system is organized into four logical layers. Data flows strictly top-to-bottom.
 LAYER 1 — WEARABLE EDGE (On-Device)
 Sensors: PVDF Piezoelectric Film (32-bit ADC) → MEMS Mic (I2S) → Differential Pressure (I2C) → Thermal Airflow (I2C)
Edge Compute: ESP32-S3 (Xtensa LX7 dual-core @ 240 MHz, 512 KB SRAM + 8 MB PSRAM)
Firmware: FreeRTOS + Arduino / ESP-IDF  |  Sampling: Piezo 1 kHz | Mic 16 kHz | Pressure/Airflow 100 Hz
Output: WiFi 4 + BLE 5.0  →  UDP streaming (~50 KB/s) with DTLS 1.3 / AES-256-GCM
Power: USB-C 5 V / Li-Po 3.7 V 2000 mAh  →  ≥ 6 h continuous operation  |  Form factor < 150 g mask
 ▼
 LAYER 2 — CLOUD SIGNAL & FEATURE ENGINEERING
 Ingestion: AWS Kinesis / Apache Kafka  →  real-time sensor frame intake (protobuf)
Feature Pipeline: 13 engineered descriptors computed per phoneme window:
RMS Amplitude  SPL (dB)  Pressure (Pa)  Velocity (m/s)  Duration (ms)  Energy Ratio  Duration Norm
SPL/Velocity Ratio  Pressure/RMS Ratio  ΔRMS  ΔSPL  ΔPressure  Phoneme-Class (categorical)
Tech: AWS Lambda / Python (Pandas, NumPy)  |  z-score or min-max normalization  |  < 100 ms per utterance
 ▼
 LAYER 3 — CLOUD INFERENCE (Deep Learning Phoneme Reconstruction)
 Model Topology (~5.5 M parameters):
Input Projection (Linear 13→32 + GELU + LayerNorm) → CNN Blocks (64→128→256, k=3, BN+GELU+Dropout 0.2)
→ 3× BiLSTM (256 hidden, bidirectional) → 4-Head Self-Attention (d_k=128, residual + LayerNorm)
→ Classification Head (LayerNorm + FC 512→256 + GELU + Dropout + FC → C classes) → Softmax
Training: AdamW (LR 2e-3, WD 1e-4)  Cosine Annealing Warm Restarts  Weighted CE + Label Smoothing ε=0.1
Runtime: PyTorch 2.x / ONNX Runtime  AWS ECS GPU (A10G / T4)  Target ≥ 100 req/s
 ▼
 LAYER 4 — LANGUAGE & SYNTHESIS
 Phoneme → Word: CMU Pronouncing Dictionary alignment + Levenshtein edit-distance recovery + beam search (width=3)
LM Re-ranking: GPT-2 / DistilGPT-2 / Indic-LM (AI4Bharat) — score = −Loss_LM(sentence); top-1 selected
TTS: FastSpeech2 (acoustic model) + HiFi-GAN (vocoder) + d-vector / x-vector speaker embedding
Output: 16-bit PCM WAV @ 22.05 kHz  MOS ≥ 3.5  TTS latency < 200 ms  Personalized from ≥ 5 min pre-loss audio
Runtime: ONNX Runtime / TensorRT  Shared GPU pool with inference service
 ▼
 OUTPUT & USER EXPERIENCE LAYER
 Companion App (Android): Real-time audio playback (< 500 ms end-to-end)  BLE pairing & calibration  Voice profile management  OTA
firmware
Clinician Dashboard: Usage analytics, phoneme accuracy trends, error logs
Offline Mode (future): Cached TTS for ~50 common phrases  Partial edge inference after quantization
APIs: POST /v1/ingest  POST /v1/synthesize  POST /v1/calibrate  GET /v1/health

6. Critical Path & Edge Roadmap
Critical Path to Commercial Launch:
1. Sensor signal validation on patients (Phase 1–2) → gates AI model reliability
2. AI model v2 training on real patient data (Phase 3) → gates clinical efficacy claim
3. 10-patient pilot completion at AIIMS Bibinagar (Phase 3) → gates regulatory submission
4. CDSCO manufacturing license (Phase 4) → gates commercial sales in India
5. FDA 510(k) / De Novo clearance (Phase 4) → gates US market entry
Edge Quantization Roadmap:
 Current: Full inference in cloud; ESP32-S3 does acquisition + streaming only.
 2027: INT8 quantization of CNN-BiLSTM (ONNX + TFLite Micro); partial phoneme classification on edge (top-3
candidates); ≤ 2 MB model size.
 2028: Evaluate ESP32-P4 or ARM Cortex-M55 + Ethos-U55 NPU for full edge inference; < 100 ms latency for 50
common phrases; cloud reserved for personalization and analytics.
